# Bike Share Big Data Analysis (≈ 6M Rows)

A data analysis project on a large-scale bike share dataset (~6 million records).  
The goal is to explore usage patterns, engineer time-based features, and produce actionable insights through efficient aggregation and visualization.

## Highlights
- Worked with a **large dataset (~6M rows)** in Python/Jupyter.
- Performed **data cleaning & transformation** and created **analysis-ready features**.
- Built analytics around **time trends**, **peak usage**, and **behavioral patterns**.
- Focused on **performance-aware analysis** for large data (efficient operations, avoiding unnecessary overhead).
